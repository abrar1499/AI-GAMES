# AI Games

Mobile games made with the [Godot Engine](https://godotengine.org) (4.3+). Each game lives in its own folder and is a complete Godot project.

| Game | Type | Folder |
|---|---|---|
| Rickshaw Rush 3D | 3D endless runner | [`rickshaw-rush/`](rickshaw-rush/) |
| Stack Tower 3D | 3D, one-tap arcade | [`stack-tower/`](stack-tower/) |
| Draw Guard | 2D physics puzzle, draw one line | [`draw-guard/`](draw-guard/) |
| Robo Siege 3D | 3D third-person shooter, waves of robots | [`robo-siege/`](robo-siege/) |

## Tools

| Tool | What it is | Folder |
|---|---|---|
| Voice to Text | Android library and demo app: speech to text with the phone's own recognizer | [`voice-to-text/`](voice-to-text/) |
